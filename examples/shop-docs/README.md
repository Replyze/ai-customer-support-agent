# Example knowledge base

Help articles for Larkspur Outdoor, a made-up online shop for outdoor gear. The agent, the tests and the eval set in [`evals/cases.json`](../../evals/cases.json) use them. Every link and email address uses the reserved `.example` domain.

Each `##` heading is one searchable section, and its id is `file.md#heading-slug`, for example `shipping.md#delivery-times`. The agent skips `README.md` files, so this one isn't searched.
